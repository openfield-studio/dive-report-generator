# 潜水作業計画・記録 記入例ジェネレーター

「潜水作業計画・記録（空気潜水用）」の記入例を、指定した日数ぶんまとめて作るWindows用ソフトの配布ページです。

## ダウンロード

[Releases（最新版）](../../releases/latest) から `DiveReportGenerator.exe` をダウンロードしてください。

- 動かすには、PCに Microsoft Excel が入っている必要があります。
- 使い方は、ソフトの画面下にある「使い方」ボタンから開けます。
- スマホから使う場合のAndroidアプリ（`DiveReportRemote.apk`）は、ソフトの「スマホ連携」画面から入れられます。同じファイルを Releases にも置いています。

## ご注意

このソフトが作るのは記入例・サンプルです。実際の潜水作業の安全書類としては使用しないでください。
